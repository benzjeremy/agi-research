# Test 8: Intrinsische Motivation & Autonome Zielgenerierung

## 1. Ausgangshypothese & Klassische Theorien ("Alte Werte")
Klassische KI-Theorien forderten stets einen externen menschlichen Befehl (Prompt / Belohnungsfunktion / Loss Function). Es wurde behauptet, KI könne niemals agieren, ohne dass ein Mensch vorher explizit das Ziel vorgegeben hat (Teleologie-Problem).

## 2. Testergebnisse & Befunde (`test_intrinsic_goals.py`)
- **Test-Setup**: Simulation von Neugier-gesteuertem Lernen (Intrinsic Curiosity Reward / Novelty Search) ohne menschlichen User-Prompt.
- **Ergebnis**: 
  - Der Agent identifizierte selbstständig 6 unbekannte Zustände und generierte 6 eigene Teilziele zur Exploration.
  - Das System zeigte autonomes Verhalten, getrieben von intrinsischer Informationsgewinnung (Predictive Error Reduction).

## 3. Widerlegung / Bestätigung
- ❌ **Widerlegt**: Die These, dass ein intelligenter Agent strikt auf passive Eingabeaufforderungen (Prompts) angewiesen ist.
- ✅ **Bestätigt**: Intrinsische Motivation und Curiosity-Drive sind notwendige Bausteine für echte AGI.

## 4. Relevanz für AGI
Heutige KI-Entwickler bauen fast ausschließlich **passive Reaktions-Systeme** (Chatbots). Eine AGI muss jedoch **aktiver Explorer** sein, der sich selbst Ziele setzt.
